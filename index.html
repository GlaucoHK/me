Agente de Monitoramento em NimMonitoring Agent in Nim

Nim · Monitoramento de sistemaSystem monitoring · Cross-platformCross-platform

Agente escrito em Nim para coleta de telemetria de hardware. Coleta RAM, CPU, GPU, armazenamento e inventario completo da maquina. Arquitetura em cascata de fallbacks: tenta primeiro APIs nativas do sistema operacional, depois utilitarios locais como CrystalDiskInfo e LibreHardwareMonitor quando presentes, garantindo cobertura mesmo em ambientes restritos.An agent written in Nim for hardware telemetry collection. It pulls RAM, CPU, GPU, storage and full machine inventory. Fallback-chain architecture: tries native OS APIs first, then local utilities like CrystalDiskInfo and LibreHardwareMonitor when present, ensuring coverage even in restricted environments.

Binario compilado leve, sem runtime pesado, com pegada de memoria minima. Ideal para rodar como agente residente sem competir por recursos com a aplicacao que monitora.Lightweight compiled binary with no heavy runtime and minimal memory footprint.
